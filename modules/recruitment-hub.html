Admin only: imports existing local browser jobs and notes into an EMPTY shared database. Create a JSON backup first.

Changes are automatically saved in this browser. On supported browsers, connect a JSON file once to also save your data to disk automatically. The file selector requires a user click and browser permission. A local HTML file may not support direct disk writing in every browser. Store regular backups outside the browser.

Import a previously exported JSON backup to restore tracker data, or import CSV to add/update jobs by job number. CSV columns include cvNeeded (Yes / No / On hold / Not set) in addition to existing job fields.

JSON restore replaces the current data after confirmation. CSV import merges by job number. No data is sent to a server.
